
# Changelog

Las fechas representan un ciclo de desarrollo simulado
para la actividad académica.

## [2.0.0] - 2026-11-10
### Changed
- Se modifico la funcion registrar_asistencia para recibir un diccionario con los datos del alumno.
- La funcion ahora permite registrar la materia del alumno.
- Breaking Change: ya no recibe directamente un DNI como cadena de texto.

## [1.1.0] - 2026-11-10
### Added
- Acumulador y contador global de asistencias en tiempo de ejecucion.

## [1.0.1] - 2026-11-09
### Fixed
- Eliminacion de espacios en blanco en el DNI escaneado.

## [1.0.0] - 2026-11-08
### Added
- Lanzamiento inicial con validacion basica de DNI.
